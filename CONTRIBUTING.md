# Contributing

1. Open an issue before proposing behavior-changing work.
2. Use a separate branch and keep pull requests small.
3. Preserve existing pages and database compatibility unless a migration is documented.
4. Do not add real user records, credentials, IP logs, or private screenshots.
5. Test changes locally with PHP, Apache, and MariaDB, and document the steps performed.

Security fixes should be reviewed carefully; this project is not production-hardened.
